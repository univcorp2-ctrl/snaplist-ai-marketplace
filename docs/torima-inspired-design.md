# Torimaを参考にした設計方針

このMVPは、写真を起点に出品準備を短くする一般的なクロスリスティングUXを参考にしています。特定サービスの画面、文言、ロゴ、配色、ソースコード、非公開APIは複製していません。

## 取り入れた一般原則

- 写真を最初の操作にする
- 入力を「写真・確認・販路別下書き・保存」の段階に分ける
- 共通の商品情報から販路別の文章へ変換する
- 商品台帳で下書き、出品中、売却済み、保留を管理する
- コピー、CSV、JSONで公式画面への手入力を短縮する

## 独自の安全設計

- 個人向けマーケットプレイスへ自動ログイン・自動投稿しない
- ID、パスワード、Cookieを収集しない
- Yahoo!フリマは他販路と同時選択できない専用掲載モード
- 写真だけで真贋、型番、傷、動作を断定しない
- API未接続時は端末内デモ生成として明示する
- 市場データ未取得時の価格は相場ではなく参考計算と表示する
